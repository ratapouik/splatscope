ⓘ Comment produire un fichier .splat ?
Cette appli visualise un modèle déjà reconstruit — la reconstruction (GPU) se fait hors-ligne, une fois :
  1. Vidéo → images (ffmpeg)
  2. Poses caméra → COLMAP
  3. Entraînement → Nerfstudio / gsplat (RTX locale ou Google Colab)
  4. Export .ply, nettoyage sur SuperSplat, puis dépôt du fichier ici
